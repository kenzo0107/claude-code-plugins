# summarize スキル: 要約(ローカルLLM)

判断を伴わない「読んで要点を抜き出す」作業をクラウドから逃がす。手動実行用の `/summarize` と同じスクリプトを使う。

## 使う場面

- 数百行を超えるログ・CI出力・テスト結果を読む必要がある
- 大きな diff の概要を把握したい(レビューや判断はしない段階)
- 長い文書・議事録の要点だけ知りたい

## 実行手順

### 1. 前提確認

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/ollama_health.py
```

- 接続できない、または `gemma4:12b` が無い場合: スキップして通常通り自分で読む(ブロッカーにしない)

### 2. 実行

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/summarize.py <ファイル|-> [--mode log|ci|diff|text] [--lines N] [--question "..."]
```

- ユーザーの目的が明確なら `--question` に渡す(例: "500エラーの原因"、"失敗したテスト名")
- `--mode` は自動判定で十分なことが多い。誤判定したら明示する

### 3. 結果の扱い

- 出力の箇条書きをそのまま提示する(自分の言葉で書き直さない)
- 要約は「入力に書かれていること」だけ。原因の判断・修正案・優先度付けが必要なら、要約を根拠にその部分だけ自分(Claude)が補う
- 要約が明らかに入力と食い違う場合は、該当箇所だけ原文を読んで訂正する

## 注意

- 巨大な入力は分割→統合で要約するため、細部が丸められる。特定の1行を探す用途には grep を使う
- モデル変更: 環境変数 `LOCAL_REVIEW_MODEL`(既定: gemma4:12b)
