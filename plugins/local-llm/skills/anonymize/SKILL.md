# anonymize スキル: 個人情報マスキング(ローカル)

個人情報を含み得るログを Claude(クラウド)に読ませる前段として、ローカルでマスクする。
手動実行用の `/anonymize` コマンドと同じスクリプトを使う。

## 使う場面

- アプリケーションログ・アクセスログ・SlowQuery ログ・DB ダンプの一部・CSV などをユーザーが分析させようとしている
- 入力にメールアドレス・IP・電話番号・氏名・住所が含まれ得る

## 実行手順

### 1. 前提確認

```bash
curl -s http://localhost:11434/api/tags
```

- 接続できない、または `gemma4:12b` が無い場合: その旨をユーザーに伝え、**マスク無しで読み進めるか確認を取る**
  (黙ってクラウドに渡さない)

### 2. 実行

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/scripts/anonymize.py <入力ファイル>
```

- `<入力>.masked.<拡張子>` が生成される。以降の分析はこのファイルだけを読む
- exit 2(マスク漏れの疑い)の場合: stderr の警告箇所をユーザーに提示し、確認が取れるまで先に進まない

### 3. 禁止事項

- 変換表 `*.map.json` を Read しない、内容を出力しない、他のツールに渡さない(個人情報そのもの)
- 元ファイルの中身を回答に引用しない

## 注意

- 正規表現は日本の電話番号(ハイフン区切り)・メール・IPv4 を対象。それ以外は LLM 検出に依存するため完全ではない
- モデル変更: 環境変数 `LOCAL_REVIEW_MODEL`(既定: gemma4:12b)
